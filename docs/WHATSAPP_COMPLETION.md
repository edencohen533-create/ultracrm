## מה נבנה (הרחבה של הארכיטקטורה הקיימת, לא מערכת מקבילה)

### בטיחות שליחה
- **סיווג שגיאות Meta** (`src/lib/meta/errors.ts`): retryable (130429 / HTTP 429 / 5xx), חוסם credential (190/10/200/131005/131031 → `revoked` + `sendingBlocked`), קבוע (131026/131047/132xxx). `MAX_AUTO_ATTEMPTS=3`, backoff 60ש → 5ד → 15ד.
- **Retry אוטומטי** (`src/jobs/campaign-runner.ts`): רק לכשל retryable, עם `requestKey` חדש לכל ניסיון (`campaign:<recipient>:a<n>`), `attempts`/`nextAttemptAt` על הנמען. rate limit עוצר את הקמפיין לשאר הריצה. **UNKNOWN (timeout) לעולם לא נשלח שוב אוטומטית.**
- **Retry מבוקר** (`retryRecipient`): FAILED מיד; UNKNOWN רק עם `confirmNotSent` מפורש (ה-UI מבקש אישור); עד 10 ניסיונות; audit `campaign.recipient_retry`.
- **שחרור מגבלת התדירות** (24ש) כאשר הספק דחה סינכרונית – אחרת retry נחסם; UNKNOWN שומר את החלון.
- **לדג׳ר סטטוסים**: כל status מהוובהוק נרשם ב-`ProviderWebhookEvent` (dedupe `id:status:timestamp`), סיבת כשל + קוד נשמרים על ההודעה, ואירוע `message.delivery_failed` מזין רצפים.
- **בריאות חיבור**: cron יומי `/api/jobs/whatsapp-health` (03:15) מריץ `checkConnection` לכל חיבור פעיל.
- **שליחת בדיקה**: רק למספרים ב-allowlist של החיבור (`testRecipients`, נערך במסך החיבור). אחרת 403.
- **חלון שעות ותקציב לדקה** חלים עכשיו על קמפיינים שיווקיים בכל הערוצים, כולל WhatsApp.

### תבניות וקמפיינים
- סנכרון תבניות ממפה כותרת IMAGE/VIDEO/DOCUMENT, כפתורים (quick_reply / url סטטי ודינמי / phone / copy_code), וסטטוסי PAUSED/DISABLED (enum חדש). מבנים לא נתמכים (LOCATION, FLOW, משתנים בשם) נשארים DRAFT עם סיבה.
- שליחת תבנית בונה `components` של Meta: כותרת מדיה בקישור, פרמטרי גוף ממוספרים, סיומת URL לכפתור דינמי. חסר → כשל ברור לפני פנייה ל-Meta.
- קמפיין: `mediaUrl` (https בלבד) + `buttonParams`; ולידציה ביצירה, בלוקר ב-preflight, `preflightSnapshot` נשמר בזמן ההתחלה; סנכרון תבניות (best effort) לפני start/resume; תבנית PAUSED/DISABLED משהה קמפיין רץ.
- משתנים: `{name}`, `{{first_name|ברירת מחדל}}`, `{{custom.שדה|ברירת מחדל}}`. משתנה ללא ערך וללא ברירת מחדל → הנמען מוחרג עם סיבה.
- אומדן עלות WhatsApp לפי מחיר ידני לשיחה שיווקית (הבסיס מוצג במפורש). תמחור Meta אמיתי **לא** מאומת.
- חיפוש קמפיינים בצד שרת, ייצוא CSV של נמענים, טבלת נמענים עם ניסיונות/קוד שגיאה/"נסה שוב".

### CRM ואוטומציות
- **מיזוג כפילויות** (`mergeContacts`, מנהל+): טלפונים, אימיילים, תגיות, לידים, עסקאות, משימות, הערות, שיחות, שיחות טלפון, טיוטות, הסרות ואירועים עוברים לראשי; הסכמה מחמירה מנצחת; audit עם snapshot; מסך כפילויות עם בחירת "ראשי".
- **רצפים**: טריגרים `CONTACT_CREATED` ו-`LEAD_STATUS_CHANGED`; שלב "משימה לנציג"; תנאי שלב (ללא תשובה / תגית / סטטוס ליד / שדה מותאם / הסכמה) עם דילוג מתועד בלוג הריצה; ריצות מופיעות בציר הזמן.
- **כללי אוטומציה**: פעולות `CREATE_TASK` ו-`SET_CUSTOM_FIELD`, תנאי "רק מחוץ לשעות הפעילות".
- קהלים: תוצאת קמפיין קודם DELIVERED / READ / REPLIED / NOT_DELIVERED.

### תפעול ודוחות
- **מדיניות שמירה** לעסק (הגדרות → דיוור → "שמירה ומחיקת מידע"): ימי שמירה להודעות ול-audit; ה-cron היומי מוחק גוף/מצורפים של הודעות ישנות (השורה נשארת לספירה) ורשומות audit ישנות.
- magic bytes בהעלאת מדיה; קישורי מעקב קליקים חתומים באימייל שיווקי (`/r/:token`); ייבוא – הורדת CSV שגיאות.
- תיבת הודעות: סינון תגית/ערוץ/צוות, סימון מספר מנותק, בורר תשובות שמורות. אנליטיקה: טווח 7/30/90 ופילוח לפי מספר.
